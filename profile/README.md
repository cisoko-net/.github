# Cisoko

FiveM resources for ESX, QBCore and Qbox servers. Every release boots and
passes its tests on all three before it ships.

- Store: https://cisoko.net
- Docs: https://cisoko.net/docs
- Discord: https://discord.cisoko.net

## Public repos

| Repo | What it is |
|---|---|
| [cis_libs](https://github.com/cisoko-net/cis_libs) | Base library that every Cisoko resource loads. |
| [cis_bridge](https://github.com/cisoko-net/cis_bridge) | One set of exports for money, items, jobs, doors and targets, with an adapter per framework and inventory. |
| [cis_database](https://github.com/cisoko-net/cis_database) | SQLite inside FXServer that provides `oxmysql`, with a MariaDB replica. |
| [cis_bfe](https://github.com/cisoko-net/cis_bfe) | BetterFight Evolved: weapon recoil, jams, a heat HUD and combat logs. |
| [cis_hes](https://github.com/cisoko-net/cis_hes) | HawkEye Surveillance: placeable CCTV with an NVR tablet and replays. |

The code is source-available under the licence in each repo. Bug reports go
to the repo's issues; questions go to Discord.
